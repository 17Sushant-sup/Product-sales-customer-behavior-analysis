# Product-sales-customer-behavior-analysis
An end-to-end data analytics project using Python, SQL and Power Bi to analyze product sales in accordance with customer shopping behavior and generate actionable business insights. 

**Author:** Sushant Singh

## 1. Project Overview

Customer Shopping Behavior Analysis is a data analytics project focused on understanding customer purchasing patterns, shopping preferences, and business trends using Python, SQL, and Power BI.

The project involves loading and exploring a dataset, performing Exploratory Data Analysis (EDA), cleaning and preprocessing data, executing SQL queries, and developing an interactive Power BI dashboard to present meaningful insights.

The objective is to transform raw customer shopping data into actionable insights that can support better business decisions.

## 2. Dataset

The project uses a customer shopping behavior dataset containing information related to customer purchases and shopping activities.

**Dataset details:**
- Customer purchasing information
- Product and category details
- Shopping patterns and preferences
- Transaction-related information

## 4. Project Steps

### Step 1: Data Loading
- Imported the dataset into Python using Pandas.
- Examined the dataset structure, dimensions, and data types.
- Reviewed the initial records to understand the available information.

### Step 2: Exploratory Data Analysis (EDA)
- Analyzed customer shopping patterns.
- Explored product and category distributions.
- Identified trends and patterns in purchasing behavior.
- Used charts and visualizations to understand the dataset.

### Step 3: Data Cleaning & Preprocessing
- Checked for missing and duplicate values.
- Handled data inconsistencies.
- Corrected data types where required.
- Prepared the dataset for further analysis.

### Step 4: SQL Analysis
- Imported the cleaned dataset into a SQL database.
- Executed SQL queries to analyze customer shopping behavior.
- Used filtering, aggregation, grouping, and joins where applicable.
- Extracted meaningful business insights from the data.

### Step 5: Power BI Dashboard
- Connected the processed dataset to Power BI.
- Created interactive visualizations.
- Used charts, slicers, filters, and KPIs.
- Designed a dashboard to communicate key findings.

### Step 6: Project Report
- Documented the complete analytical workflow.
- Summarized the findings and insights.
- Presented potential business recommendations.
